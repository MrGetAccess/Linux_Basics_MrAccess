# Linux Basics Commands

## 1. Navigation Commands

### pwd - Present Working Directory
```bash
pwd
```

### ls - List Files
```bash
ls
ls -l
ls -a
```

### cd - Change Directory
```bash
cd /home
cd ..
cd ~
```

## 2. File Management Commands

### mkdir - Create Directory
```bash
mkdir myfolder
```

### touch - Create File
```bash
touch file.txt
```

### cp - Copy File
```bash
cp file.txt backup.txt
```

### mv - Move or Rename File
```bash
mv old.txt new.txt
```

### rm - Remove File
```bash
rm file.txt
```

## 3. System Commands

### whoami - Current User
```bash
whoami
```

### date - Current Date
```bash
date
```

### df - Disk Space
```bash
df -h
```

### free - Memory Usage
```bash
free -h
```

## 4. File Permissions

### chmod - Change Permissions
```bash
chmod 755 script.sh
chmod +x script.sh
```

## 5. Search Commands

### find - Find Files
```bash
find . -name "file.txt"
```

### grep - Search Text
```bash
grep "hello" file.txt
```

## 6. Process Commands

### ps - List Processes
```bash
ps aux
```

### top - Monitor Processes
```bash
top
```

## 7. Help Commands

### man - Manual
```bash
man ls
```

### history - Command History
```bash
history
```

### clear - Clear Terminal
```bash
clear
```
